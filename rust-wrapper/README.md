# OpenPano Rust Wrapper

Cross-platform panorama stitching library with bindings for Python, iOS (Swift), and Android (Kotlin).

## Architecture

```
┌─────────────────────────────────────┐
│  Python / Swift / Kotlin            │  ← High-level APIs
│  (Generated by UniFFI)              │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│  Rust Safe Wrapper                  │  ← Safe Rust API
│  (rust-wrapper/src/lib.rs)          │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│  Rust FFI Layer                     │  ← Unsafe FFI calls
│  (rust-wrapper/src/ffi.rs)          │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│  C API Wrapper                      │  ← C-compatible interface
│  (src/c_api/openpano_c.{h,cc})      │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│  C++ Core (OpenPano)                │  ← Original implementation
│  (src/stitch/*, src/feature/*)      │
└─────────────────────────────────────┘
```

## Building

### Prerequisites

- **Rust**: Install from https://rustup.rs/
- **CMake**: 3.20 or later
- **C++ Compiler**: gcc/clang with C++11 support
- **Eigen3**: Linear algebra library
- **libjpeg** (optional): JPEG support

### Build Steps

```bash
# 1. Build the Rust wrapper (this also builds the C++ core)
cd rust-wrapper
cargo build --release

# 2. Run tests
cargo test

# 3. Generate language bindings (optional, done automatically)
cargo run --features=uniffi/cli --bin uniffi-bindgen generate \
    src/openpano.udl --language python --out-dir ../bindings/python
```

## Usage

### Rust

```rust
use openpano::{Stitcher, StitcherConfig};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut stitcher = Stitcher::new()?;
    
    stitcher.add_image("img1.jpg")?;
    stitcher.add_image("img2.jpg")?;
    stitcher.add_image("img3.jpg")?;
    
    let panorama = stitcher.stitch()?;
    panorama.save("output.jpg")?;
    
    println!("Panorama: {}x{}", panorama.width(), panorama.height());
    Ok(())
}
```

### Python

```python
from openpano import stitch_panorama, PanoConfig

# Simple usage
panorama = stitch_panorama(["img1.jpg", "img2.jpg", "img3.jpg"], None)
panorama.save("output.jpg")

# With configuration
config = PanoConfig(
    cylinder_mode=False,
    estimate_camera=True,
    crop=True,
    focal_length=37.0,
    max_output_size=8000
)
panorama = stitch_panorama(image_paths, config)
print(f"Size: {panorama.width()}x{panorama.height()}")
```

### Swift (iOS)

```swift
import OpenPano

let imagePaths = ["img1.jpg", "img2.jpg", "img3.jpg"]

do {
    let panorama = try stitchPanorama(imagePaths: imagePaths, config: nil)
    try panorama.save(path: "output.jpg")
    print("Size: \(panorama.width())x\(panorama.height())")
} catch {
    print("Error: \(error)")
}
```

### Kotlin (Android)

```kotlin
import com.openpano.*

val imagePaths = listOf("img1.jpg", "img2.jpg", "img3.jpg")

try {
    val panorama = stitchPanorama(imagePaths, null)
    panorama.save("output.jpg")
    println("Size: ${panorama.width()}x${panorama.height()}")
} catch (e: PanoException.StitchError) {
    println("Error: $e")
}
```

## Platform-Specific Build Instructions

### Python Package

```bash
# Install maturin
pip install maturin

# Build wheel
cd rust-wrapper
maturin build --release

# Install locally
pip install target/wheels/*.whl

# Or develop mode
maturin develop
```

### iOS Framework

```bash
# Install cargo-lipo
cargo install cargo-lipo

# Add iOS targets
rustup target add aarch64-apple-ios x86_64-apple-ios

# Build universal library
cargo lipo --release

# The .a file will be in target/universal/release/
# Create XCFramework using Xcode or xcodebuild
```

### Android AAR

```bash
# Install cargo-ndk
cargo install cargo-ndk

# Add Android targets
rustup target add aarch64-linux-android armv7-linux-androideabi \
    i686-linux-android x86_64-linux-android

# Build for all Android architectures
cargo ndk -t armeabi-v7a -t arm64-v8a -t x86 -t x86_64 \
    --platform 21 build --release

# Libraries will be in target/<arch>/release/
```

## Configuration Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `cylinder_mode` | bool | false | Use cylindrical warping |
| `estimate_camera` | bool | true | Estimate camera parameters |
| `trans_mode` | bool | false | Translation mode (vs rotation) |
| `ordered_input` | bool | false | Images are in sequence |
| `crop` | bool | true | Crop black borders |
| `focal_length` | f32 | 37.0 | Focal length (35mm equiv) |
| `max_output_size` | i32 | 8000 | Max output dimension |

## Performance Tips

1. **Downscale large images** before stitching (4MP or less recommended)
2. **Use ordered_input=true** if images are sequential (faster)
3. **Disable crop** if you don't mind black borders (faster)
4. **Use cylinder_mode** for pure rotation captures

## Troubleshooting

### Build fails with "Eigen3 not found"

```bash
# macOS
brew install eigen

# Ubuntu/Debian
sudo apt install libeigen3-dev

# Or set manually
export Eigen3_DIR=/path/to/eigen3/cmake
```

### Link errors on macOS

```bash
# Make sure you're using the right compiler
export CXX=g++-11  # or clang++
```

### Android build fails

Make sure you have Android NDK installed and set:
```bash
export ANDROID_NDK_HOME=/path/to/ndk
```
